## Description

This repository contains a C++ user-mode research project related to RageMP.

The project is intended to help understand user-mode application structure, overlays, rendering concepts, process interaction, and general Windows programming.

The current version only contains basic ESP-related code. Other features are not implemented.

## Features

- C++ user-mode project
- Overlay-related code
- DirectX 9 related project files/libraries
- Basic ESP-related structure
- ImGui included
- Research/learning-focused codebase

## Project Status

This project is currently experimental and incomplete.

Only the ESP-related part exists at the moment.  
Other features may be added or changed in the future.

## Educational Purpose

This repository is only a learning project.

It is intended to help understand:

- C++ project structure
- Windows user-mode programming
- Overlay rendering concepts
- ImGui usage
- DirectX-based rendering basics
- General reverse-engineering research concepts
